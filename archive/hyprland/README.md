# Hyprland & Waybar Archive

This directory stores archived Hyprland and Waybar configurations from the Fedora workstation prior to the migration to KDE Plasma 6.
- `hyprland-backup-20260914_213036.tar.gz`: Hyprland configuration, binds, hyprpaper, hyprlock, and scripts.
- `waybar-backup-20260914_214244.tar.gz`: Waybar modules and styles.
